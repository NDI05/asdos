# Perbaikan QA dan Alur Soal + Bobot

Tanggal: 3 November 2026. Ini catatan perubahan dan bukti terbaru, melengkapi laporan QA awal. **Kode alur baru telah diuji; inference Qwen nyata masih terhalang lingkungan dan belum dinyatakan aktif.**

## Alur untuk pengguna

1. Buat asesmen dan impor PDF soal atau tulis pertanyaannya.
2. Untuk PDF berteks, pilih Gunakan sebagai daftar soal dan periksa hasil pemisahan nomor. PDF gambar memiliki fallback OCR lokal jika Qwen tersedia.
3. Isi bobot per nomor. Tidak ada kewajiban mengetik kunci atau kriteria.
4. Pilih Buat acuan otomatis. Worker Qwen menyusun jawaban acuan, alternatif dan kriteria dari soal saja, tanpa jawaban mahasiswa.
5. Tinjau draft lalu Setujui acuan. Acuan AI tidak mengaku sebagai kunci resmi, tidak disahkan model sendiri, dan tidak otomatis mengesahkan nilai mahasiswa.
6. Tambahkan mahasiswa, unggah PDF jawaban, tunggu halaman tampil, periksa nama/NIM dan konfirmasikan secara eksplisit.
7. Petakan region jawaban, baca tulisan dan minta usulan penilaian. Teks tidak terbaca ditahan untuk review.
8. Tinjau keputusan, sahkan snapshot, lalu ekspor Excel.

## Perbaikan yang diterapkan

| Area | Perubahan |
| --- | --- |
| Soal + bobot | Endpoint question-seeds menerima input tanpa reference_answer/criteria; formulir utama tidak meminta kunci |
| Acuan otomatis | Job rubric_generate pada worker; schema ketat, ModelRun, audit, version/fingerprint, lease, cancellation dan outbox/recovery |
| Kendali angka | Model tidak dapat mengubah ID, teks soal, urutan atau bobot pengguna; kalkulasi Decimal tetap di domain |
| Keterbacaan | Marker/teks kosong menjadi flag; worker menyimpan status unreadable; proposal/keputusan biasa/finalisasi melalui kriteria ditahan sampai masalah diselesaikan |
| Identitas | Upload tidak lagi otomatis memanggil confirm-identity; preview dan konfirmasi terpisah; claimed_identity ditandai sebagai data belum terverifikasi |
| Impor PDF soal | Teks hasil impor dapat dipisahkan ke daftar soal; halaman tanpa text layer dicoba OCR lokal, bukan dianggap ekstraksi berhasil dengan teks kosong |
| Job lokal eager | Hasil selesai langsung segera dimuat, error ditampilkan; UI tidak menunggu polling untuk job yang sudah selesai |
| Endpoint proposal | Import QuestionRevision yang hilang diperbaiki setelah E2E baru mereproduksi NameError |
| Readiness model | Manifest saja tidak cukup: file bobot harus hadir, tidak kosong, dan berada di direktori model. Status memisahkan siap dimuat dari loaded/inference_verified pada proses tersebut |
| Inferensi | Generation lock, deteksi output terpotong, dan konteks independen untuk transkripsi/generasi rubrik/penilaian |
| Provisioning | Verifikasi keberadaan bobot/shard; make setup-model memasang runtime, provisioning lalu smoke test tiga tugas |
| Migrasi | 0002_rubric_jobs mengizinkan document_id NULL hanya untuk job assessment generation pada service; job dokumen tetap wajib memiliki document_id |

Override manual beralasan oleh dosen tetap tersedia untuk penyelesaian akademik; sistem tidak mengubah unreadable menjadi nol secara otomatis. Acuan hasil model tetap draft sampai ditinjau dan disahkan.

## Bukti pengujian

- Backend: **38 tes lulus** pada suite penuh.
- Frontend: **5 tes lulus**, termasuk pemisahan dua soal bertoken Linux dan payload tanpa kunci jawaban.
- TypeScript/Vite production build lulus.
- Compileall dan git diff --check lulus.
- Migrasi SQLite baru ke head 0002 lulus pada database sementara.
- Database development lokal yang sudah ada dibackup memakai SQLite backup API ke data/backups, lalu migrasi 0001 → 0002 berhasil. Data tidak ditampilkan atau dikirim keluar.
- E2E API baru: input soal+bobot tanpa kunci → generasi acuan fake berlabel → persetujuan → upload/render PDF sintetis → konfirmasi identitas → transkripsi fake → proposal fake → keputusan dosen → finalisasi → workbook delapan sheet. Pembaca openpyxl memverifikasi NIM berawalan nol dan nilai100.00. Nilai tersebut milik fixture, bukan penilaian PDF pengguna.
- Regression: output rubrik invalid, stale input, cancel, replay job failed, draft tanpa rubrik, bobot invalid, ketidakpastian tulisan dan finalisasi tertahan.

Fake model hanya digunakan melalui patch pada tes. Runtime normal tetap memakai adapter Qwen lokal; tidak ada jawaban hardcoded atau API eksternal sebagai fallback tersembunyi. Tes ini membuktikan integrasi/kontrak, bukan akurasi handwriting atau kebenaran ilmiah acuan dari model.

## Penghalang Qwen yang masih nyata

Upaya `uv sync --locked --extra model --extra test` dengan cache writable sudah dilakukan. Unduhan paket gagal setelah retry karena DNS files.pythonhosted.org. Akses Hugging Face juga gagal DNS. Cache model lokal tidak berisi checkpoint Qwen dan runtime .venv belum memiliki torch/transformers yang diperlukan. Model lain yang ada di perangkat tidak digunakan sebagai pengganti diam-diam.

Smoke test nyata mengembalikan `inference_not_verified`, `MODEL_UNAVAILABLE`, exit2. Tidak ada bukti load/inference Qwen yang berhasil pada sesi ini. Karena itu fitur pembuatan acuan dan analisis tulisan belum dapat dipakai dengan Qwen nyata sampai paket dan checkpoint tersedia.

Server native dicoba pada 127.0.0.1:8012; startup aplikasi berhasil tetapi bind socket ditolak dengan operation not permitted. Uji browser penuh, stack Compose, benchmark tulisan tangan dan dua PDF asli belum selesai. Tidak ada klaim server sedang berjalan atau aplikasi siap produksi.

## Penyiapan pada terminal dengan akses yang diperlukan

```bash
cd <root-repository>
make setup-model
make migrate
make dev-api
```

Pada terminal lain jalankan make dev-web. Setup-model harus menyelesaikan tiga tahap (runtime/checkpoint/inference); jika gagal, jangan menganggap Qwen aktif. Jangan mengatasi blokir dengan mengirim data mahasiswa ke API berbayar atau mengubah model tanpa keputusan eksplisit.

## Batas kesiapan

Perbaikan source dan tes terkait selesai. Qwen nyata dan pengujian browser masih blocked oleh akses jaringan/socket. Dataset, rubrik AI, dan hasil penilaian tetap memerlukan review dosen serta evaluasi pada sampel berizin sebelum klaim akurasi dibuat.
